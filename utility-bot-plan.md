# Utility-Agent Development Plan

## Overview

Build a Telegram bot that possesses utility functions such as storing meeting links, notes, and reminders. Users will be able to store information in a database and retrieve it later, therefore authentication will be required.

## Requirements

- [ ] Users should be able to register/login using their phone number via Telegram
- [ ] Store meeting links
- [ ] Store notes
- [ ] Store reminders
- [ ] Retrieve information
- [ ] Database for storage
