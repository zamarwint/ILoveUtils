# Utility Agent

A Telegram bot that provides various utility functions to users. Users can store and retrieve information.

## Features

- Registration/login using phone number or other methods
- Store meeting links
- Store notes
- Store reminders

## Tech Stack

- Node.js
- Express
- TypeScript
- PostgreSQL
